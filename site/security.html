Enterprise Security Whitepaper

Security Architecture & Hardening

How DeckMind AI satisfies enterprise information security standards through sandboxed execution and zero-trust engineering.

Manifest V3 Native

DeckMind AI is strictly built on Google's modern Manifest V3 extension platform. No remote scripts or dynamic code evaluation (eval()) are permitted or used.

Strict Content Security Policy

Enforces script-src 'self'; object-src 'self'. External CDN scripts, web trackers, or malicious code injection vectors are blocked at the browser engine level.

Sandboxed File Generation

Slide decks (.pptx), Word docs (.docx), and Excel sheets (.xlsx) are generated via compiled client-side byte streams in browser memory, eliminating server-side file staging risks.
