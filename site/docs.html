DeckMind AI Documentation

Everything you need to know about customizing frameworks, local LLM proxying, procedural vector rendering, and keyboard workflows.

1. In-Browser Client-Side Engine (Default)

By default, DeckMind AI requires zero external software or server configuration. The extension runs entirely inside Google Chrome using native JavaScript DOM scrapers and PptxGenJS compilation. Simply install the extension and use it on any supported chat page.

2. Local Ollama LLM Integration (Optional)

If you run local open-source models via Ollama, you can direct DeckMind AI to use local models such as llama3.2, mistral-nemo, or deepseek-r1 for offline slide summarization:

1. Start Ollama with CORS enabled: OLLAMA_ORIGINS="*" ollama serve
2. Open DeckMind AI Options / Settings page.
3. Under Open-Source LLM Orchestration, select Local Ollama Service.
4. Enter your model name (e.g., llama3.2) and click Test Ollama Connection.

3. Local Stable Diffusion WebUI Integration (Optional)

To generate custom AI visual assets directly into your PowerPoint slides using local diffusion models (AUTOMATIC1111 or ComfyUI):

1. Launch your Stable Diffusion WebUI with the API flag: --api --cors-allow-origins="*"
2. In DeckMind AI Settings, set Visual Mode to Local Stable Diffusion WebUI.
3. Set endpoint to http://localhost:7860 and verify connection.

4. Supported File Exports

• Microsoft PowerPoint (.pptx): 16:9 widescreen presentation with native shapes and text.
• Microsoft Word (.docx): Structured executive brief and essay.
• Microsoft Excel (.xlsx): Extracted tabular metrics and comparison matrices.
• Vector Diagrams (.svg): Clean vector architecture diagrams for documentation.
• Plaintext (.txt): Clean markdown summary notes.
